Buttons

Click = tap. Hold >400 ms, >2 s or >5 s for the three hold tiers.

Backup

Holds button 1 (1!), which makes the device type the backup on HID1 — into whatever window has focus. The countdown is your window to click into an editor. Needs the device unlocked.

Send to HID4 (debug)

Enter sends it, and a newline is added if you omit one. Digits 1-6 are buttons and run in order, so 1234567 types a PIN; add !, !! or !!! for the three hold tiers, or # ticks for an exact duration. 8 restarts; 0C wipes userspace and 9C wipes everything.
